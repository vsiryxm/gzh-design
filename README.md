# 公众号文章排版器 · gzh-design

Markdown 贴进去，右边直接看到手机里的样子，点一下复制，粘到公众号编辑器就是排好的效果。
**不用跑 AI，不用联网，不传一个字。**

![界面](docs/screenshot.png)

## 简介

单文件、零依赖、零构建的公众号排版工具。把「排版规则」从 AI 提示词里固化成确定性模板——同输入同输出，不等模型、不花钱、不跑偏。

- **六套主题**：摸鱼绿 / 红白色系 / 石墨极简 / 留白禅意 / 摸鱼票据 / 橄榄手记
- **双预览**：手机 375px 真机宽度 / PC 677px 桌面微信阅读宽度
- **一键复制**：写 `text/html` + `text/plain` 双 MIME，粘过去样式不丢；另可下载 HTML 归档
- **纯本地**：文章只存在浏览器 localStorage，没有后端

## 快速使用

```bash
npm start        # → http://127.0.0.1:5173
```

也可以直接双击 `index.html`（剪贴板 API 在 `file://` 下偶尔被拦，起本地服务器最稳）。

1. 左边贴 Markdown —— 首次打开自带一份覆盖全部语法的示例，直接改或全删重写
2. 顶部挑风格，右上角可切深色 / 浅色界面
3. 点右下角「复制到公众号」，到编辑器里 ⌘V

## 支持的语法

```md
# 文章标题（只记文章名，不渲染）    ## 章节（自动编号）    ### 小节
**加粗**  ==高亮==  ++下划线++  ~~删除~~  `行内代码`
> 引用      - 无序列表      1. 有序列表      三个反引号 = 代码块
![说明](图片地址)      ---
```

链接只保留文字（公众号正文外链点不到）。完整对照见 [docs/PRD.md](docs/PRD.md)。

## 六套主题

摸鱼绿 · 红白色系 · 石墨极简 · 留白禅意 · **摸鱼票据（默认）** · 橄榄手记

不是「一套结构换六个颜色」——章节标题、列表、引用、小节标题都是各主题自己的一套。
